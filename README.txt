CHRONOTHERAPY ML — PROTOTYPE UI 0.1
Identitas: apt. Fendy Prasetyawan, S.Farm., M.Farm.
Judul: Pengembangan Model Prediksi Kronoterapi untuk Penentuan Waktu Pemberian Obat Antihipertensi

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di Chrome, Edge, atau Firefox.
3. Gunakan menu Dashboard, Eksplorasi Pasien, Perbandingan Model, dan Metodologi.

Status:
Prototype antarmuka penelitian. Belum ada model ML yang dilatih; tidak menghitung probabilitas prediksi klinis, tidak terhubung ke rekam medis, dan tidak menyimpan input pasien. Metrik model belum tersedia karena data training dan validasi belum disiapkan.

Penting:
Jangan menggunakan prototype ini untuk menentukan atau mengubah waktu/dosis obat pasien. Luaran, label, dan algoritma perlu ditetapkan dalam protokol penelitian dan divalidasi sebelum penggunaan klinis.
